# Задание: «Последние новости» Коврова

Декораторы на реальной задаче: парсим блок «Последние новости» с главной
страницы [kovrov-gorod.ru](https://kovrov-gorod.ru/) (официальный сайт
администрации города). Функции, которые работают с сетью и селекторами,
защищаем **собственными декораторами**: что бы ни случилось (таймаут,
пропавший селектор), наружу всегда уходит аккуратная JSON-строка со статусом —
ни одного голого исключения.

## Разведка

Сайт статический — контент лежит прямо в HTML, JavaScript для парсинга не
нужен (проверь сам: `curl -s https://kovrov-gorod.ru/ | head -100`, тексты
новостей будут видны в выдаче).

Открой страницу в браузере, найди через DevTools блок «Последние новости».
Структура примерно такая:

```
<div id="newsbox">           — контейнер блока «Последние новости»
  <div class="newsitem">     — одна новость
    <h3>...</h3>             — заголовок
    <div class="pub-date">   — дата публикации
    <div class="nextnews">
      <a href="/press/news/NNNNN.html">  — ссылка «подробнее»
```

Из неё собери CSS-селекторы для заголовков и ссылок (проверить селектор можно
прямо в DevTools: `Ctrl+F` в панели Elements).

Важная деталь про кодировку: сервер отдаёт HTML в **windows-1251**, но не
сообщает об этом в заголовке `Content-Type` — если довериться `response.text`
без поправок, русский текст превратится в кашу. Кодировку нужно выставить
самому (`response.encoding = "windows-1251"`) до того, как читать `.text`.

## Шаг 1. Декоратор `catch_network(errormessage)`

Декоратор **с параметром** (три уровня вложенности — фабрика, декоратор,
обёртка) для функций, которые ходят в сеть. Поведение:

- функция отработала → вернуть её результат как есть;
- `requests.exceptions.Timeout` → вернуть JSON-строку вида
  `{"status": "error", "error": "timeout", "message": errormessage}`;
- `requests.exceptions.ConnectionError` → такой же JSON, но `"error": "connection"`.

JSON собирай через `json.dumps(..., ensure_ascii=False)` — иначе русский текст
превратится в `\uXXXX`. Не забудь `functools.wraps` на обёртке.

## Шаг 2. Декоратор `guard_selector(errormessage)`

Декоратор для функций, которые вынимают данные по CSS-селектору и возвращают
список найденного. Поведение обёртки:

- список не пустой → вернуть JSON-строку
  `{"status": "ok", "count": <сколько>, "data": [...]}`;
- список пустой или `None` → вернуть JSON-строку
  `{"status": "error", "error": "элемент не найден", "message": errormessage}`.

Подумай, где здесь понадобится захват `errormessage` замыканием через два
уровня. И снова — `functools.wraps`.

## Шаг 3. Функции-добытчики

- **`fetch_html(url, timeout=10)`** — скачивает страницу и возвращает HTML
  строкой, с поправкой на кодировку (см. разведку выше). Таймаут и ошибки сети
  сам не глушит — их ловит `@catch_network`.
- **`get_news_titles(html, selector=...)`** — задекорирован
  `@guard_selector("заголовки не найдены")`. Принимает HTML строкой, возвращает
  список строк — заголовки всех новостей блока (`select` + `get_text`).
- **`get_news_links(html, selector=...)`** — задекорирован
  `@guard_selector("ссылки не найдены")`. Возвращает список **полных** URL на
  тексты новостей: достань атрибут `href` у ссылок «подробнее» и преобразуй
  через `urllib.parse.urljoin(BASE_URL, href)`.

Сделай CSS-селектор необязательным параметром функции с разумным значением по
умолчанию — так удобно проверять декоратор на заведомо неверном селекторе.

## Шаг 4. `demo()`

Функция `demo()`, которая:

1. Качает страницу: `fetch_html(BASE_URL)`. Результат — либо HTML, либо
   JSON-строка об ошибке; отличи их и обработай (например, проверкой, что
   строка начинается с `{`, или `json.loads` + проверка поля `status`).
2. Печатает нумерованный список заголовков из `get_news_titles`
   (`json.loads` → проверка `status` → `data`).
3. Печатает ссылки из `get_news_links`.
4. Показывает, что декораторы реально работают: вызови `get_news_titles` с
   заведомо несуществующим селектором и напечатай ответ — должен прийти JSON
   «элемент не найден»; вызови `fetch_html` с `timeout=0.001` и напечатай
   ответ — должен прийти JSON про таймаут.

Сайт при отладке не дёргай в цикле — скачай HTML один раз в переменную и
гоняй добытчики по ней.
