## 1. Циклы `for` и `while`

`for` перебирает **готовую последовательность** (список, строку, диапазон):

```python
for fruit in ["яблоко", "банан", "вишня"]:
    print(fruit)
```

`while` повторяет блок, **пока условие истинно** — когда заранее не знаем число
повторений:

```python
balance = 100
while balance > 0:
    balance -= 30
```

Правило выбора простое:

- знаешь, **что перебирать** → `for`;
- знаешь, **до какого условия** крутить → `while`.

В Python **нет** `do { ... } while (...)`. Если нужно «выполнить хотя бы один раз» —
пишут `while True:` с `break` внутри.

⚠️ В `while` обязательно меняй то, что влияет на условие, иначе получишь
**бесконечный цикл**.

### `range` — управляем числами

`range` создаёт последовательность целых чисел. Три формы:

```python
range(5)          # 0, 1, 2, 3, 4         — стоп (не включая)
range(2, 6)       # 2, 3, 4, 5            — старт, стоп
range(0, 10, 2)   # 0, 2, 4, 6, 8         — старт, стоп, шаг
range(10, 0, -1)  # 10, 9, ... , 1        — обратный отсчёт
```

`range` **не создаёт список в памяти** — числа генерируются по одному. Если список
всё-таки нужен, оберни в `list()`: `list(range(1, 6))` → `[1, 2, 3, 4, 5]`.

## 2. `enumerate` и `zip`

### `enumerate` — индекс и значение сразу

Часто нужен не только элемент, но и его **номер**. Вместо ручного счётчика:

```python
for i, fruit in enumerate(fruits):
    print(i, fruit)
```

Нумерацию можно начать не с нуля: `enumerate(fruits, start=1)`.

### `zip` — несколько списков параллельно

`zip` склеивает последовательности и отдаёт элементы **попарно**:

```python
for name, score in zip(names, scores):
    print(f"{name}: {score} баллов")
```

Если списки разной длины — `zip` останавливается на **самом коротком**. Удобно
собирать словарь из двух списков: `dict(zip(names, ages))`.

## 3. `break`, `continue`, `else` в циклах

- `break` — выйти из цикла досрочно.
- `continue` — пропустить текущий шаг и перейти к следующему.

### `else` у цикла

У циклов в Python есть необычная конструкция — `else`. Она срабатывает, **если цикл
завершился сам, без `break`**:

```python
for guess in range(1, 6):
    if guess == secret:
        print("угадал!")
        break
else:
    print("не нашли число в диапазоне")   # break не сработал → сюда
```

Мнемоника: `else` здесь означает «**no break**» — «прошли весь цикл, и ничего не
прервало». Без `else` пришлось бы заводить отдельный флаг-переменную.

## 4. Списки и их методы

Список — упорядоченный, изменяемый набор элементов. Главные методы:

| Метод            | Что делает                                       | Пример                 |
|------------------|--------------------------------------------------|------------------------|
| `append(x)`      | добавить элемент в конец                          | `nums.append(4)`       |
| `extend([...])`  | добавить сразу несколько                          | `nums.extend([5, 6])`  |
| `insert(i, x)`   | вставить по индексу                               | `nums.insert(0, 9)`    |
| `remove(x)`      | удалить первое вхождение значения                 | `nums.remove(1)`       |
| `pop(i)`         | удалить и вернуть элемент (по умолч. последний)   | `last = nums.pop()`    |
| `sort()`         | отсортировать на месте                            | `nums.sort()`          |
| `reverse()`      | развернуть на месте                               | `nums.reverse()`       |
| `count(x)`       | сколько раз встречается                            | `nums.count(2)`        |
| `index(x)`       | индекс первого вхождения                           | `nums.index(2)`        |

Важная разница: `sort()` меняет сам список и возвращает `None`, а `sorted()`
возвращает **новый** список, не трогая исходный.

Срезы (slices) работают для чтения и копирования:

```python
data = [10, 20, 30, 40, 50]
data[1:4]    # [20, 30, 40]
data[::-1]   # разворот
copy = data[:]   # полная копия
```

## 5. List comprehension — генераторы списков

Очень часто мы создаём новый список на основе старого. Вместо цикла с `append`:

```python
squares = []
for n in range(1, 6):
    squares.append(n ** 2)
```

то же самое одной строкой:

```python
squares = [n ** 2 for n in range(1, 6)]
```

Общая форма:

```
[выражение for элемент in последовательность if условие]
```

С фильтром: `[n for n in range(1, 11) if n % 2 == 0]` → `[2, 4, 6, 8, 10]`.

Та же идея работает для словарей и множеств:

```python
{n: n ** 2 for n in range(1, 4)}        # {1: 1, 2: 4, 3: 9}
{len(w) for w in ["a", "bb", "cc"]}     # {1, 2}
```

Когда **не** стоит использовать comprehension: если внутри сложная логика на
несколько строк — обычный цикл читается лучше.

## 6. Кратко: кортежи, множества, словари

Эти типы пригодятся в практике.

**Кортеж (`tuple`)** — как список, но **неизменяемый**; удобен для «склеенных»
значений и распаковки: `x, y = (10, 20)`.

**Множество (`set`)** — набор **уникальных** элементов без порядка. Идеален, чтобы
убрать дубликаты (`list(set(...))`) и быстро проверять принадлежность (`x in s`).

**Словарь (`dict`)** — пары «ключ → значение», главный инструмент для подсчётов и
сводок. Частый приём — счётчик через `.get()`:

```python
counts = {}
for tag in ["bug", "ui", "bug"]:
    counts[tag] = counts.get(tag, 0) + 1   # {'bug': 2, 'ui': 1}
```
