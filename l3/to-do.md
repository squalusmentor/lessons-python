# Задание: LeetCode 1. Two Sum

Одна задача, чтобы применить циклы и структуры данных из урока не на игрушечном
примере, а на классической задаче.

## Условие

[1. Two Sum](https://leetcode.com/problems/two-sum/) (Easy). Дан список целых
чисел `nums` и число `target`. Нужно вернуть индексы **двух** элементов
списка, сумма которых равна `target`.

Пример: `nums = [2, 7, 11, 15]`, `target = 9` -> `[0, 1]`, потому что
`nums[0] + nums[1] == 9`.

Условия:

- Решение существует и оно одно (гарантируется задачей) — можно не думать
  про случай «пары нет».
- Один и тот же элемент дважды использовать нельзя (индексы должны быть разные).
- Порядок индексов в ответе значения не имеет.

## Как реализовывать

Решение в лоб — два вложенных цикла, перебрать все пары — работает, но на
больших списках медленное (квадратичная сложность). Смысл задачи — решить её
**за один проход по списку**, с помощью словаря: пока идёшь по числам, храни в
словаре уже увиденные значения и их индексы (`{значение: индекс}`). На каждом
шаге проверяй, не встречалось ли уже число `target - nums[i]` — если да, ответ
найден сразу, второй проход не нужен.

Оформи как функцию `two_sum(nums, target)`, возвращающую список из двух
индексов.
