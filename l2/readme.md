## 1. Условия

### if / elif / else

Условный оператор уже встречался в первом уроке. Соберём ключевые особенности Python:

- **Скобки вокруг условия не нужны** — просто `if` и выражение.
- **Двоеточие `:`** в конце строки с `if`, `elif`, `else` — обязательно.
- **Вложенность определяется отступами**, а не фигурными скобками. Принято 4 пробела. Смешивать табы и пробелы нельзя — Python ругается ошибкой `IndentationError`.
- `elif` — это сокращение от `else if`. В Python именно `elif`, а не `else if` и не `elseif`.

### Истинность значений (truthy / falsy)

В Python в условии можно писать не только булевы выражения. Любое значение неявно приводится к `bool`. **Ложными** считаются: `False`, `None`, `0`, `0.0`, `""`, `[]`, `{}`, `()`, `set()`. Всё остальное — **истина**.

Поэтому `if nums:` — это идиоматичная проверка «список не пуст». Писать `if len(nums) > 0:` не нужно.

### Тернарный оператор (условное выражение)

Python поддерживает однострочный аналог `if/else` — **условное выражение**:

```python
parity = "чётное" if n % 2 == 0 else "нечётное"
```

Удобно, когда нужно выбрать одно из двух значений. Не злоупотребляй: вложенные тернарники читаются плохо.

### match / case

С Python 3.10 появился оператор `match` — это **структурный pattern matching**, а не просто аналог `switch`. Базовое использование действительно похоже на switch из других языков:

```python
match day:
    case 1: ...
    case 2 | 3: ...
    case _: ...   # default
```

Особенности:

- `|` — несколько значений в одном `case`.
- `case _:` — обработчик «по умолчанию» (`_` — wildcard).
- Падения вниз (fallthrough), как в C, **нет** — после совпадения выходим.
- Можно матчить структуру: списки, словари, классы. Но это уже продвинутая тема, на которую вернёмся позже.

Для простой замены длинной цепочки `if/elif` чаще пишут именно `if/elif/else` — это идиоматичнее.

## 2. Циклы

В Python два цикла: `for` и `while`.

### for

`for` в Python — это **итерация по коллекции**, а не классический счётчик `i = 0; i < n; i++`, как в C/Go. Чтобы пройти по числам, используют `range()`:

- `range(n)` — числа `0, 1, ..., n-1`.
- `range(a, b)` — `a, a+1, ..., b-1` (правая граница не включена).
- `range(a, b, step)` — с шагом, можно отрицательным.

`range` возвращает **ленивый объект**, а не список. Память не выделяется заранее — числа генерируются по мере итерации. Это важно: `range(10**9)` не съест всю память.

### while

`while условие:` — обычный цикл с проверкой условия в начале. Бесконечный цикл — `while True:`, выход через `break`.

В Python **нет** конструкции `do { ... } while (...)`. Если нужно «выполнить хотя бы один раз», пишут `while True:` с `break` в нужном месте.

### break и continue

- `break` — выйти из ближайшего цикла.
- `continue` — перейти к следующей итерации, пропустив остаток текущей.

### for ... else / while ... else

Уникальная для Python штука: к циклу можно приписать блок `else`. Он выполнится, **если цикл завершился естественно** — без `break`. Если был `break` — `else` пропускается.

Полезно для поиска: «прошли по всему и не нашли — сделать X». Без `else` пришлось бы заводить флаг.

```python
for x in nums:
    if x == target:
        print("нашли")
        break
else:
    print("не нашли")
```

### enumerate и zip

При итерации часто нужен индекс. Писать `for i in range(len(nums)):` и потом `nums[i]` — **неидиоматично**. Правильно:

```python
for i, val in enumerate(nums):
    ...
```

Когда надо параллельно идти по двум коллекциям — `zip`:

```python
for name, age in zip(names, ages):
    ...
```

`zip` тоже ленивый; остановится по короткой из коллекций.

### Итерация по строке

В Python строка — это последовательность **символов** (формально `str` длины 1). Никаких рун, байтов и индексов в UTF-8: `for ch in "Привет":` просто даёт по одному символу. Это удобно — никаких сюрпризов с многобайтовыми символами.

## 3. Функции

Функция объявляется через `def`. Имена — `snake_case`.

### Объявление

```python
def add(a, b):
    return a + b
```

Никаких типов в обязательном порядке. Но Python поддерживает **type hints** — необязательные аннотации:

```python
def add(a: int, b: int) -> int:
    return a + b
```

Это **подсказки**, а не проверка: рантайм не следит за ними. Их используют редакторы, линтеры (`mypy`, `pyright`) и читатели кода. В реальных проектах type hints — норма.

### Значения параметров по умолчанию

В Python можно задать значение по умолчанию прямо в сигнатуре:

```python
def greet(name, greeting="Привет"):
    print(f"{greeting}, {name}!")
```

**Ловушка**: значение по умолчанию вычисляется **один раз** при объявлении функции, а не при каждом вызове. Поэтому **нельзя использовать изменяемые объекты** (`[]`, `{}`) как дефолт — они будут переиспользоваться между вызовами. Идиома: писать `None` и создавать пустой объект внутри.

### Позиционные и именованные аргументы

При вызове аргументы можно передавать **по позиции** или **по имени**:

```python
greet("Аня")
greet(name="Аня", greeting="Здравствуй")
```

Именованные аргументы делают вызов читаемее, особенно когда параметров много.

### *args и **kwargs

Аналог вариативных функций из Go, но мощнее:

- `*args` — собирает оставшиеся **позиционные** аргументы в кортеж.
- `**kwargs` — собирает оставшиеся **именованные** аргументы в словарь.

```python
def total(*nums):
    return sum(nums)

total(1, 2, 3)        # 6
total(*[1, 2, 3])     # распаковка списка
```

### Несколько возвращаемых значений

В Python нет «нескольких возвращаемых значений» в смысле Go. Но функция может вернуть **кортеж**, который сразу распаковывается:

```python
def divmod_(a, b):
    return a // b, a % b   # вернули кортеж

q, r = divmod_(17, 5)      # распаковали
```

Семантически — то же самое, что в Go. Просто реализовано через кортежи.

### Ошибки

В Go идиома — возвращать `(результат, error)`. В Python путь другой — **исключения**. Если что-то пошло не так — поднимают исключение через `raise`, а ловят через `try/except`. Возвращать пару `(значение, ошибка)` непринято.

```python
def divide(a, b):
    if b == 0:
        raise ValueError("деление на ноль")
    return a / b
```

Это глубокая тема, к ней вернёмся отдельно.

### lambda — анонимные функции

Короткие однострочные функции можно записать через `lambda`:

```python
square = lambda x: x * x
square(5)   # 25
```

Лямбда — это **выражение**, поэтому внутри только одно выражение, без `return` и без `if/else`-блоков (только тернарный вид). Если логика длиннее одной строки — пиши обычный `def`. PEP 8 не любит присваивание лямбды переменной: для именованной функции используй `def`.

### Замыкания

Вложенная функция видит переменные внешней — это замыкание:

```python
def multiplier(x):
    def inner(y):
        return x * y
    return inner

double = multiplier(2)
double(5)   # 10
```

Захваченные переменные продолжают жить вместе с возвращённой функцией.

Если нужно **изменить** захваченную переменную внутри замыкания — пиши `nonlocal имя` (для переменной из внешней функции) или `global имя` (для модульного уровня). Без этого Python создаст локальную переменную при присваивании.

### Рекурсия

Функция может вызывать сама себя. Нужна **база** — условие, при котором функция возвращает результат без рекурсивного вызова.

**Особенность Python**: лимит глубины рекурсии — по умолчанию **1000** вызовов. Дальше — `RecursionError`. **Хвостовой оптимизации нет** и в обозримом будущем не будет — таково сознательное решение разработчиков языка (об этом писал Гвидо). Поэтому глубокую рекурсию (например, обход дерева на миллион узлов) в Python переписывают **итеративно** или через явный стек.
