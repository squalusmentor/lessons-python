# python-lessons
Авторский курс по Python

## Уроки

Основной курс — по порядку, каждый следующий опирается на предыдущие.

| Урок | Тема |
|---|---|
| [l1](l1) | Переменные, машинный код, условия |
| [l2](l2) | Условия, циклы, функции |
| [l3](l3) | Циклы, списки и генераторы списков |
| [l4](l4) | Функции вглубь (`*args`/`**kwargs`, замыкания, функции высшего порядка) и рекурсия |
| [l5](l5) | ООП: от классов до паттернов |
| [l6](l6) | Декораторы и парсинг HTML (BeautifulSoup) |
| [l7](l7) | Итераторы и генераторы |

`advanced/` — модули поверх основного курса, предполагают, что `l1`–`l7` уже пройдены.

| Урок | Тема |
|---|---|
| [advanced/b1](advanced/b1) | Асинхронность: event loop, GIL, aiohttp |
| [advanced/b2](advanced/b2) | FastAPI: первое приложение, роуты, разделение на слои |
| [advanced/b3](advanced/b3) | Базы данных: сырой SQL, async-драйверы и ORM |
| [advanced/b4](advanced/b4) | FastAPI на боевом примере: JWT, БД, Docker |
| [advanced/b5](advanced/b5) | Телеграм-бот на aiogram |

Структура и принципы, которым следуют уроки, — в [CLAUDE.md](CLAUDE.md).
