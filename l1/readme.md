Сначала — компиляция в байткод. Когда ты запускаешь .py файл, Python читает твой текст и компилирует его в байткод — это промежуточный, более компактный набор инструкций

Потом — исполнение виртуальной машиной (PVM). Байткод читает и выполняет Python Virtual Machine — это цикл внутри самого интерпретатора CPython, который берёт каждую инструкцию байткода и код ня языке C. Вот этот C-код уже компилируется в настоящие машинные инструкции и процессор их исполняет

Поэтому Python называют интерпретируемым — нет отдельного шага "скомпилировать всё заранее в .exe", как в C или Go. Интерпретатор сам стоит между твоим кодом и железом и управляет каждым шагом во время выполнения. Это даёт гибкость (динамические типы), но за это платишь скоростью — каждая инструкция проходит через лишний слой

Всё в Python — объект. Число 42, строка "привет", функция, список — каждое из этих значений хранится в памяти как объект. У каждого объекта три вещи: тип, значение и счётчик ссылок.

можешь написать:
x = 42        # x указывает на int
x = "привет"  # теперь x указывает на str
Python не ругается, потому что x — просто ярлык, ему всё равно на что вешаться.
Когда мы делаем х=42 то мы заводим в памяти целочисленный объект и просто ссылаемся на него в переменной

машинный код показать
Положить 10 в регистр eax - на машинном коде B8 0A 00 00 00  →  mov eax, 10 (ассемблер)
Прибавить 7 к eax  -  83 C0 07        →  add eax, 7
Вернуть eax -  C3              →  ret

## условия (if / elif / else)

Условный оператор позволяет программе принимать решения: выполнять разный код в зависимости от того, истинно или ложно некоторое выражение.

Базовый синтаксис:
```
if условие:
    # выполняется, если условие True
elif другое_условие:
    # выполняется, если первое False, а это True
else:
    # выполняется, если все условия выше False
```

Важно:
- После `if`, `elif`, `else` ставится двоеточие `:`.
- Тело блока обязательно с отступом (обычно 4 пробела) — Python определяет вложенность по отступам.
- `elif` и `else` необязательны: можно писать только `if`, можно `if` + `else`, можно цепочку `if / elif / elif / else`.

Операторы сравнения: `==` (равно), `!=` (не равно), `<`, `>`, `<=`, `>=`.

Логические операторы: `and` (и), `or` (или), `not` (не) — для объединения условий.

Оператор `%` (остаток от деления) часто используется в условиях: например, `n % 2 == 0` — проверка на чётность.

В файле собраны базовые примеры (возраст, температура, логин/пароль, знак числа, високосный год) и пара задач: оценка по баллам, чётное/нечётное, поиск максимума из трёх чисел.
