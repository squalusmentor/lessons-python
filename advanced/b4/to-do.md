# Задание: маленький сервис «users»

Заведи **новый репозиторий в Git** и собери в нём маленький FastAPI-сервис
«users». Никакой БД — данные пока не храним нигде, цель домашки — отработать
**роуты, схемы и коды ответа**.

Сделай **два эндпоинта**:

1. **Создание пользователя — `POST /users`**
   - Принимает тело JSON, описанное pydantic-схемой (например: `first_name`,
     `last_name`, `email`, `password`). `email` сделай через `EmailStr`.
   - Никуда пользователя не сохраняй. Задача — только **валидация**: если тело
     корректное, верни `200` (например `{"message": "valid"}`). Если тело кривое
     (нет поля, не тот тип, мусор вместо email) — FastAPI **сам** вернёт `422`,
     отдельно это писать не надо.

2. **Получение пользователя — `GET /users/{user_id}`**
   - Если `user_id == "001"` — верни `200` и фейкового пользователя, например:

     ```json
     {"id": "001", "first_name": "Иван", "last_name": "Тестовый", "email": "ivan@example.com"}
     ```

   - Для любого другого `user_id` — верни `404`.

## Минимальные требования

- проект запускается через `uvicorn main:app --reload`;
- оба эндпоинта работают и проверяются прямо из Swagger UI (`/docs`);
- в `README.md` репозитория — пара строк, как запустить;
- в `requirements.txt` — `fastapi`, `uvicorn[standard]`, `pydantic[email]`;
- коммиты осмысленные (хотя бы «init», «add POST /users», «add GET /users/{id}»).

## Подсказки

- Структуру подглядывай в референс-проекте (см. `readme.md` этого урока), но
  сильно урезанную: хватит одного `main.py` или связки `main.py` +
  `routers/users.py` + `schemas/user.py`.
- Проверить руками без Swagger:
  `curl -X POST localhost:8000/users -H "Content-Type: application/json" -d '{"first_name":"Иван","last_name":"Тест","email":"i@x.ru","password":"123"}'`.
